## What the video shows

Hoodit is deployed on Aomi's runtime from [build.aomi.dev](https://build.aomi.dev). An Aomi app is described as a compiled Rust bundle of its own tools, skills and guards, similar to a ChatGPT plugin or a Claude connector, and it runs without MCP.

Hoodit brings in data APIs for stock token insights and copy trading, and uses Aomi's transaction pipeline for onchain actions. In the recording they stake 10 USDG to Spark Vault even though Hoodit has no Spark Vault integration in the app itself.

Connecting a GitHub repo means each push is built and verified before it goes live. Payment health tracks money in and out. The last-day figures in the recording: 112 chats, 272 tool calls, 21 confirmed transactions and 505 model credits. Every tool shows its calls, errors and last error message.

## How to deploy an app of your own

1. Open [build.aomi.dev](https://build.aomi.dev).
2. Create or connect a project. The Hoodit video shows a GitHub repo as the source, with a build and verification on each push.
3. Follow the [first App guide](/guides/first-app) if you are starting from an empty folder: wrap your API as tools, add a system prompt, and deploy.
4. After the app is live, use the activity and log views the way the video does: check tool calls, errors and payment health before you share the app.

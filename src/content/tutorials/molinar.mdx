## What the video shows

Matt (Molinar) and Cecilia (Aomi) talk about Mochi, a 3D voxel bunny used as an AI companion. Matt describes Molinar as "Roblox for iMessage." Adding an AI friend was a way to solve a cold-start problem, but hosting many companions was expensive.

The official description says Molinar is a multiplayer web game with 1000+ users, and that Aomi powers the AI companion for each user concurrently, which lowers Molinar's infrastructure cost. Molinar users settle game-asset transactions onchain through Aomi. The description also says Aomi will power other UGC generation, which is a product statement from the video page, not something I independently verified.

The recording is a conversation about that integration, not a step-by-step build tutorial. I am not inventing a Molinar setup guide from the chat.

## If you want a similar app integration

Use the public Aomi surfaces the same way other apps do:

1. Build or host an App at [build.aomi.dev](https://build.aomi.dev). See the [first App quickstart](https://aomi.dev/docs/build/first-app).
2. Put a chat UI in your product with the [widget](https://aomi.dev/docs/guides/widget/widget-installation) or call the [Client SDK](https://aomi.dev/docs/integrate/client-sdk).
3. Keep settlement non-custodial: the agent proposes, the user's wallet signs, as described in the [Portal](https://aomi.dev/docs/trade/portal) signing model.

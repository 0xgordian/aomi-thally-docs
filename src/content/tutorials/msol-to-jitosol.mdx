This page is based on the official video title and description, plus Aomi's public docs. I could not get captions for this recording, so the exact on-screen clicks were not independently verified.

The official description says the recording shows route selection, simulation, wallet-approval instructions and a follow-up balance check. It is a silent product demo, and it is not a recommendation to hold either asset.

Aomi's [docs introduction](https://aomi.dev/docs) uses the same example: "Move my entire mSOL position over to JitoSOL," routed through Jupiter, with simulation passed and the transaction staged for approval.


## How to try this in the portal

These steps come from the [Portal](https://aomi.dev/docs/trade/portal) guide.

1. Open [chat.aomi.dev](https://chat.aomi.dev).
2. Connect a wallet or sign in when you are ready to transact.
3. Set the network in the header to the chain used in the recording.
4. Type the same kind of request the video describes.
5. Review the simulation in the chat, then sign in your wallet only if you want to send it. Rejecting the prompt does nothing onchain.


Set the thread to Solana, then ask Aomi to move an mSOL position into JitoSOL. The portal docs note that Solana requests are signed and sent without a fork simulation, so review the transaction details in your wallet. I did not re-run this rotation.

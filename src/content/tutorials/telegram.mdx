## How to put an App on Telegram today

Follow [Put your App on Telegram](https://aomi.dev/docs/build/telegram):

1. Deploy an App from [build.aomi.dev](https://build.aomi.dev).
2. Use the Telegram guide to connect that App as a hosted bot.
3. In Telegram, use the wallet deep link shown in the product, then sign in your own wallet.

I could not verify the exact deep-link UI from captions, so use the current Telegram docs for the clicks.

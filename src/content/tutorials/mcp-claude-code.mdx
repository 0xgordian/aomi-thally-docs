## What the video shows

The demo prepares a swap of 15 USDC to ETH on Ethereum mainnet. The speaker's preview account has 24 USDC. Instead of the web portal, the request goes through Aomi's MCP, "the same interface a Claude Code agent would use."

Aomi then:

1. Activates the LiFi swap skill (an approved LiFi spender appears later)
2. Confirms the Ethereum mainnet context
3. Fetches a fresh quote
4. Simulates the entire transaction onchain

The simulation result shown in the recording includes the 15 USDC input, the expected output, the Aomi fee and the gas cost. It passes. Two transactions are staged: an approval for the exact 15 USDC LiFi spender, and the swap itself. A link sends the user back to the portal to confirm. The wallet still has to approve. If either transaction would fail, the simulation stops and explains why.

## Try it yourself

Add Aomi's Agent server to Claude Code:

```bash
claude mcp add --transport http aomi-agent \
  https://chat.aomi.dev/v1/agent/mcp
```

Run `/mcp` and authenticate `aomi-agent` if the browser doesn't open. Then ask Claude Code to prepare a small USDC to ETH swap on Ethereum. The swap comes back as a pending Action. Approve it in the portal, where your wallet signs. OAuth lets Claude Code call Aomi. It never gives it your key.

Setup for Codex, Cursor and other clients is in [Connect an MCP client](/guides/mcp). The tool names the current server exposes (`aomi_chat`, `aomi_check` and others) are listed in the [MCP tools reference](/reference/mcp-tools) and may differ from the recording.

This page is based on the official video title and description, plus Aomi's public docs. I could not get captions for this recording, so the exact on-screen clicks were not independently verified.

The official description lists what the recording covers:

- Fetch availability of aomi.eth from ENS
- Interact with the ENS controller for 1 year of registration
- Commit to the registry with a transaction (didn't register...)

The last line is important: the recording commits, and the description says it did not complete registration.

To explore a similar flow today, ask Aomi at [chat.aomi.dev](https://chat.aomi.dev) to check an ENS name and, if you intend to register, review every transaction before signing. I did not send any ENS transactions, and you should not assume `aomi.eth` is still available.

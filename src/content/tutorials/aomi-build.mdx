## What the description says it shows

The recording tours [Aomi Build](https://build.aomi.dev), the developer platform for creating and managing Aomi Apps. It covers projects, the build workflow, deployment, activity views, provider settings and Telegram connections.

## How to use Build

From the public [Developer Platform](https://aomi.dev/docs/build/developer-platform) and [first App](https://aomi.dev/docs/build/first-app) docs:

1. Open [build.aomi.dev](https://build.aomi.dev).
2. Create an App. The first-app guide covers going from an empty folder to a deployed App, including the crate layout and `aomi.toml` described in [Aomi App](https://aomi.dev/docs/build/plugins/aomi-app).
3. Deploy and then use the activity views to see how the App behaves, the same surfaces the Hoodit video shows in more detail.
4. If you want a Telegram bot, follow [Put your App on Telegram](https://aomi.dev/docs/build/telegram) rather than guessing at the UI from this animated tour.

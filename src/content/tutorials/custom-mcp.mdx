## How to connect Aomi's MCP today

The recording shows the older in-product flow for plugging an MCP server into Aomi. Today the common direction is the reverse: you connect your MCP client to Aomi's Agent or Pipeline server. For Claude Code:

```bash
claude mcp add --transport http aomi-agent \
  https://chat.aomi.dev/v1/agent/mcp
```

Run `/mcp` and authenticate if the browser flow does not start. The old `/api/mcp` paths are removed.

Codex, Cursor and other clients are covered in [Connect an MCP client](/guides/mcp).

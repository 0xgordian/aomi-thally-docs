## How to connect Aomi's MCP today

The current docs are about connecting an MCP client to Aomi's Agent or Pipeline servers, which is the reverse direction of a "custom MCP server inside Aomi" UI. I could not verify the older in-product connection screen from captions, so use the current docs for anything you connect today:

```bash
claude mcp add --transport http aomi-agent \
  https://chat.aomi.dev/v1/agent/mcp
```

Run `/mcp` and authenticate if the browser flow does not start. Retired paths such as `/api/mcp` should not be used.

If you specifically need the in-app "connect a custom MCP server" flow shown in the video, watch the recording for that older UI. I cannot faithfully reconstruct its clicks from the title and description alone.

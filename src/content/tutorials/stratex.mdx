StratEx is an Early Forge project built on Aomi. It is an AI trading agent that learns your strategy, then trades it for you. You stay the one who signs. Instead of shipping one hardcoded strategy, a short plain-English setup asks which indicators you read, which thresholds matter, and related preferences.

StratEx has no public setup guide. To build something similar on Aomi:

- Try chat and signing in the [Portal](/guides/portal)
- Build a similar agent as an App from [build.aomi.dev](https://build.aomi.dev) using the [first App guide](/guides/first-app)

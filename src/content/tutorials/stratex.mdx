This page is based on the official video title and description, plus Aomi's public docs. I could not get captions for this recording, so the exact on-screen clicks were not independently verified.

The official description says StratEx is an Early Forge project built on Aomi. It is an AI trading agent that learns your strategy, then trades it for you. You stay the one who signs. Instead of shipping one hardcoded strategy, a short plain-English setup asks which indicators you read, which thresholds matter, and related preferences.

I do not have a public step-by-step product guide for StratEx itself. If you want the underlying Aomi pieces:

- Try chat and signing in the [Portal](https://aomi.dev/docs/trade/portal)
- Build a similar agent as an App from [build.aomi.dev](https://build.aomi.dev) using the [first App quickstart](https://aomi.dev/docs/build/first-app)

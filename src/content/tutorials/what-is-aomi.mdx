## What the video shows

Victor (DevRel at Aomi Labs) walks the rebuilt site and announces that Aomi is backed by Anagram and Nascent, with additional angels listed in their launch thread.

He describes Aomi as a hosted runtime that executes protocol-agnostic transactions, then lists four product surfaces:

- A human interface
- Embeddable widgets that put a transaction-capable assistant inside your app
- Agent tooling: MCP, CLI and skills, so Claude Code, Cursor or another agent can execute onchain
- A REST API and clients for direct integration, plus a plugin SDK when you need to customize the runtime

He also mentions solution areas (fintech, DeFi, trading and wallets) and production examples from the recording: Sommelier for liquidity management, World Markets composing APIs into an app on [build.aomi.dev](https://build.aomi.dev) and shipping Telegram trading, and Lex Steward (built by community members) planning and simulating vault reallocations. Signing stays non-custodial. Policy checks run outside the model, and each transaction is rehearsed on a fork before it reaches a wallet.

## How to look at the current product

The site has changed since this recording. Start from the current pages, not from screenshots in the video:

1. Read the current overview at [aomi.dev](https://aomi.dev) and [aomi.dev/docs](https://aomi.dev/docs).
2. Try the hosted chat at [chat.aomi.dev](https://chat.aomi.dev). The [Portal](https://aomi.dev/docs/trade/portal) guide covers connecting a wallet or signing in, asking in plain English, then reviewing the simulation before you sign.
3. If you want an agent in your editor, follow [Agents with MCP](https://aomi.dev/docs/guides/mcp).
4. If you want to ship an App, use [Aomi Build](https://aomi.dev/docs/build/developer-platform) at [build.aomi.dev](https://build.aomi.dev).

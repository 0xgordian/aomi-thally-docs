In this quickstart you install `@aomi-labs/client`, send two messages to the Aomi Agent in the same session, and print the reply. It runs in guest mode, so you don't need an API key or an OAuth client.

## Prerequisites

- Node.js 20 or later, with npm, pnpm or yarn
- A terminal with internet access to `https://chat.aomi.dev`

```bash
node --version
```

## 1. Install the Aomi SDK

Create a project folder, then install the client and a TypeScript runner.

<CodeGroup>

```bash npm
mkdir aomi-quickstart && cd aomi-quickstart
npm init -y
npm install @aomi-labs/client
npm install --save-dev tsx @types/node
```

```bash pnpm
mkdir aomi-quickstart && cd aomi-quickstart
pnpm init
pnpm add @aomi-labs/client
pnpm add -D tsx @types/node
```

```bash yarn
mkdir aomi-quickstart && cd aomi-quickstart
yarn init -y
yarn add @aomi-labs/client
yarn add -D tsx @types/node
```

</CodeGroup>

## 2. Set the API origin

Point the SDK at the production runtime:

```bash
export AOMI_BASE_URL="https://chat.aomi.dev"
```

Keep the origin in configuration rather than in code. Staging and production can run different API versions during a rollout.

## 3. Write the script

Create `example.ts`:

```ts example.ts
import { Aomi, type MessageEvent } from "@aomi-labs/client";

const aomi = new Aomi({ baseUrl: process.env.AOMI_BASE_URL! });

// One session ID = one conversation. Reuse it to keep context.
const sessionId = crypto.randomUUID();

await aomi.agent.run("Remember that my demo color is cobalt.", { sessionId });

const result = await aomi.agent.run("Reply with only my demo color.", {
  sessionId,
});

console.log(lastAgentText(result.messages));

function lastAgentText(messages: readonly MessageEvent[]) {
  return [...messages].reverse().find((m) => m.sender === "agent")?.content;
}
```

On the first request the SDK creates an anonymous guest session. `agent.run()` starts the turn and follows its event stream until the turn finishes, so each `await` returns a complete result.

## 4. Run it

```bash
npx tsx example.ts
```

The agent replies with the color from the first turn:

```text
cobalt
```

<Note>
Guest sessions have a concurrency limit. If the second call fails with `429` and `guest_concurrency_limit`, the first turn is still being processed. Wait a few seconds and run the script again, and respect the `Retry-After` header in production code. See [Troubleshooting](/resources/troubleshooting#guest-concurrency-limit).
</Note>

## What you built

- A `new Aomi({ baseUrl })` client in guest mode
- A conversation that keeps context because both turns share one `sessionId`

Store the `sessionId` with your own conversation record to continue it later. A session ID continues a conversation. It is not a credential.
